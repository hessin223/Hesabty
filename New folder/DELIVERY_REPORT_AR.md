# تقرير تسليم ومراجعة حسابتي

تاريخ المراجعة: 26 أكتوبر 2026

## التغييرات المنفذة

- لوحة تحكم هاتفية محسنة: فلاتر اليوم و7 أيام والشهر الحالي/السابق، ملخص التدفق، اختصارات حقيقية، أرصدة الحسابات، توزيع المصروفات وحالات فارغة صادقة.
- تنبيهات مبنية على بيانات فعلية فقط: أصناف المخزون عند حد التنبيه، مستحقات الدفع الشخصي، وآخر نسخة احتياطية ناجحة.
- تسجيل وقت نجاح تصدير النسخة الاحتياطية محليًا، مع استعادة محمية بتأكيد المستخدم.
- إزالة اعتماد خط Google الخارجي؛ الواجهة لا تحتاج شبكة لعرض الخط.
- إصلاحات محاسبية: رفض التواريخ المستحيلة، منع حذف الحساب المرتبط بعمليات، منع فواتير المورد المكررة والدفعات فوق المستحق، والتحقق من القيم السالبة.
- تجميع تصنيفات هرمي كامل دون مضاعفة الإجمالي، ومنع احتساب دفعة فاتورة المشروع مرتين ضمن تكلفته.
- حفظ الإعدادات ومفاتيح منع التكرار في SQLite الأصلي، وإضافة `package-lock.json` واستخدام `npm ci` في GitHub Actions.

| التحويلات | جزئية | تحويل داخلي ورسومه متاحان؛ التحويل لشخص بحالات مخططة/منفذة غير منفذ. |
| التصنيفات | جزئية قوية | إنشاء شجرة متداخلة وحساب صحيح؛ لا توجد واجهة تعديل/حذف. |

| المخزون | جزئية | صنف وحركات وحد تنبيه في المحرك؛ الواجهة غير مكتملة. |
| الأصول | جزئية | إضافة وقيمة منفصلة في المحرك؛ الواجهة غير مكتملة. |
| المهام | جزئية | إنشاء وإتمام في المحرك؛ الواجهة غير مكتملة. |
| التحويشة والأموال الشخصية | جزئية | أهداف الادخار والدفع الشخصي للمشروع في المحرك؛ الواجهة غير مكتملة. |
| الميزانيات والتقارير | جزئية | ميزانيات في المحرك وملخص/تصنيفات في الواجهة؛ لا يوجد تصدير تقرير. |
| المرفقات | جزئية | بيانات وصفية فقط؛ لا يوجد حفظ ملف ثنائي بعد. |
| إقفال اليوم/الشهر | جزئية | قفل فترة ومنع قيود رجعية في المحرك؛ لا توجد واجهة إقفال أو قيود تصحيح. |
| النسخ الاحتياطي والاستعادة | مكتملة أساسيًا | JSON بإصدار المخطط، تحقق، تأكيد واستعادة SQLite ذرية. |
| الإعدادات | جزئية | إعدادات عامة محفوظة؛ لا توجد إدارة متقدمة. |

## نتائج التحقق الفعلية

- `npm test`: نجح، 15 اختبارًا من 15.
- فحص TypeScript: نجح بعد إصلاح حدود الأنواع؛ تعذر تكراره بعد آخر تعديل واجهة بسيط لأن تثبيت npm في البيئة أصبح غير مكتمل أثناء ربط الحزم.
- بناء Vite النهائي: غير مؤكد. تعطّل لاحقًا بسبب تثبيت npm غير مكتمل في البيئة (ربط حزم `typescript` و`rollup`)؛ لا توجد نتيجة بناء ناجحة مُدعاة.
- مزامنة Capacitor وبناء APK: لم ينفذا محليًا؛ لا يوجد Android SDK/Gradle مُتحقق منه هنا.
- GitHub: لم يُنشأ commit أو push أو رابط APK؛ لم يتوفر مستودع Git صالح أو صلاحية رفع.

## التشغيل والرفع

```bash
npm ci
npm test
npm run build
npx cap add android   # مرة واحدة فقط إذا لم يوجد android/
npx cap sync android
cd android
./gradlew assembleDebug
```

بعد رفع الملفات، شغّل GitHub Actions. يُنزّل APK من تبويب Actions ثم Artifacts باسم `hesabty-android-debug-apk`.

## عيوب متبقية

- يلزم إكمال واجهات CRUD للوحدات الجزئية قبل استخدامها كدفتر تشغيل كامل.
- لم يجر اختبار Android فعلي أو اختبار محاكي عند عروض 360 و390 و430 بكسل.
- المرفقات لا تحفظ الملف نفسه حاليًا؛ لا ينبغي اعتبارها مرفقات مكتملة قبل تخزين المحتوى والنسخ الاحتياطي له.
