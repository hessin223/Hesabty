# تقرير تسليم الجولة الثانية — حسابتي

تاريخ التسليم: 26 أكتوبر 2026

## ما نُفذ

- لوحة تحكم محسنة بتدرج بصري أوضح، فلاتر فترة، بطاقات أرصدة وتوزيع مصروفات، رسم أعمدة تفاعلي للدخل/المصروف لآخر سبعة أيام، وحالات فارغة لا توحي ببيانات غير موجودة.
- تعديل الحسابات مع إعادة الحساب عبر المحرك، وسجل الحركات المرتبط بكل حساب داخل واجهة الحسابات.
- تعديل العمليات المالية من السجل نفسه مع استبدال أثر العملية وإعادة الحساب، وليس إضافة أثر جديد.
- تحويلات إلى شخص بحقول المستلم ووسيلة التحويل والغرض والحالة. التحويل المخطط لا يخصم الرصيد ولا يدخل الملخص؛ التحويل المنفذ يخصم الأصل والرسوم، والرسوم فقط تعد مصروفًا.
- واجهات تشغيل فعلية لإضافة مهام وإتمامها، عمال وحركات أجر/سلفة/صرف، موردين وفواتير جزئية، أصناف وحركات مخزون، أصول، وأهداف التحويشة وحركاتها.
- مرفقات فعلية حتى 2 ميجابايت (صور أو PDF) تحفظ كبيانات Base64 محليًا، ترتبط بعملية اختيارية، وتدخل النسخة الاحتياطية. التخزين في Android يتم من خلال `domain_store` داخل SQLite.
- واجهة إقفال يوم/شهر مع تأكيد واضح، وسجل فترات مقفلة. سياسة التصحيح موثقة داخل الواجهة: قيد جديد في فترة مفتوحة بدل تعديل القيد المقفل.
- ترقية مخطط SQLite إلى الإصدار 3: ترحيلات مسلسلة عبر `PRAGMA user_version`، وجدول تفاصيل التحويلات الشخصية، مع ترحيل جدول العمليات لاستيعاب النوع الجديد.
- انتقالات ضغط وتركيز وحركة دخول خفيفة تحترم `prefers-reduced-motion` الموجود في التنسيقات السابقة.

## ما اختُبر فعليًا

- `npm test`: نجح 16/16، بما فيها اختبار جديد للتحويل الشخصي المخطط/المنفذ والرسوم.
- `node --check src/services/ledgerCore.mjs`: نجح.
- التحقق من عدم وجود مستودع Git في المصدر المسلّم: لا يوجد commit أو push أو GitHub Actions قيد التشغيل.

## ما لم يُختبر ولم يُدّع نجاحه

- فحص TypeScript وبناء Vite: لم يكتمل لأن `npm ci` في هذه البيئة أنشأ تثبيتًا جزئيًا للحزم وغياب `tsc` و`vite` التنفيذيَّين؛ لا توجد نتيجة بناء ناجحة.
- SQLite الأصلي على Android: لم يُختبر، لعدم وجود جهاز/محاكي Android متصل. الكود مهيأ للترحيل الذري، لكن يلزم اختبار Android فعلي بعد `npx cap sync android`.
- APK وGitHub Actions: لم يُبنَ APK ولم يُرفع Artifact؛ لا يوجد اتصال بمستودع GitHub.
- اختبار مرئي على عروض 360/390/430 بكسل لم ينفذ عبر متصفح أو محاكي في هذه البيئة.

## حالة الوحدات بعد الجولة

| الوحدة | الحالة |
|---|---|
| الرئيسية والحسابات والعمليات والتحويلات | مكتملة أساسيًا في الواجهة والمحرك |
| المهام والعمال والمشتريات والموردون والمخزون والأصول والتحويشة | مكتملة للإنشاء والحركات/العرض الأساسية؛ تعديل وحذف كل سجل ليسا مكتملين بعد |
| المرفقات | مكتملة ضمن حد 2 ميجابايت للتخزين المحلي والنسخ الاحتياطي؛ لا يوجد ضغط ملفات أو معاينة PDF مدمجة |
| الإقفال | مكتمل للإقفال والمنع؛ التصحيح يتم بقيد جديد ولا توجد شاشة مساعد تصحيح مستقلة |
| النسخ الاحتياطي | التصدير/التحقق/الاستعادة موجودة؛ اختبار Android الأصلي ما زال مطلوبًا |

## خطوات التحقق التالية

```bash
npm ci
npm test
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

بعد رفع المصدر إلى GitHub، شغّل Workflow الموجود. لا تنشر APK أو تعتمد SQLite قبل تنفيذ اختبار إنشاء/إعادة فتح/تصدير/استعادة على جهاز Android فعلي.
